### ⚡ The Problem
In *ARC Raiders*, inventory management is stressful. You are mid-raid, your backpack is full, and you find a "Broken Radio." Do you drop it? Do you keep it for a quest? Do you recycle it for parts?

### 🛠 The Solution
**The Loot Oracle** is a lightweight, instant-search utility that answers one question: **Keep, Sell, or Recycle?**

Unlike general wikis that force you to read long articles, this tool provides:
* **Instant Verdicts:** specific "Keep" or "Sell" flags.
* **Profit Logic:** A mathematical comparison of an item's Sell Price vs. its Recycled Component value.
* **Zero Friction:** No login required. No loading screens. fast search.

### ✨ Features
* **Real-time Search:** Filters the database instantly as you type.
* **Recycle Calculator:** Automatically checks if breaking an item down yields more value than selling it raw.
* **Responsive Design:** Looks great on a second monitor or a mobile phone while playing.

### 🤝 Contributing (Help keep the database alive!)
This project relies on accurate game data. If you find an item in-game that isn't listed or has changed stats:
1.  Fork this repository.
2.  Open `index.html` (or `data.json` if separated).
3.  Add the item details.
4.  Submit a Pull Request!
